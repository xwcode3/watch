维度队列信号量 / 互斥量任务通知事件组

      
内核对象需要需要不需要需要

相对开销高（memcpy+链表）中最低中

      
ISR 可用性FromISR 版FromISR 版FromISR 版受限（走定时器守护任务）

      
典型场景数据流、命令传递资源互斥 / 事件计数轻量信号、ISR→任务多条件任意/全部组合

    

    
选型口诀：要传数据 → 队列；要保护资源 → 互斥量（有继承防饿死）；要计数 → 计数信号量；只发信号 → 任务通知（最快）；多条件组合 → 事件组。
