# MPU6050 驱动 · 测试记录台账

> 工程：STM32F411CEU6 + FreeRTOS + SPL · 硬件 I2C1 (PB6/PB7, 400kHz) · GY-521 (AD0=GND, 0x68)
> 台账规则：每轮验证新增一行，**不删改历史行**；结论列只写 PASS / FAIL / PARTIAL + 一句话；失败项须在下轮复测并引用前轮编号。
> 数据来源约定：原始值 = `bsp_imu_get_stats()` 与 `pf_read_raw` 输出；换算值 = `pf_read_data` 输出。

---

## 1. 验证项清单

| 编号 | 验证项 | 方法 | 判据 |
|---|---|---|---|
| V1 | WHO_AM_I 器件身份 | 上电读 0x75 | 返回 0x68，无 BAD_ID 错误码 |
| V2 | 静止加速度合理性 | 模块水平静置桌面读 10 次 | 重力轴 0.95~1.05g；水平两轴 \|值\|≤0.05g |
| V3 | 静止陀螺零偏 | 同上 | 三轴 \|dps\| ≤ 1.5（上电初期放宽 2.0） |
| V4 | 温度合理性 | 同上 | 环境温度 +3~5℃（芯片自热），±2℃ 内波动 |
| V5 | 动态响应 | 手动转动模块 ±90° | 对应轴 dps 出现明显起伏后回零 |
| V6 | 长稳测试 | 连续运行 ≥30 分钟（默认 100Hz） | 无死锁；`err_count` 不增长（或仅初始 few 次）；read_count 持续增长 |
| V7 | 错误恢复 | 运行中拔插 SDA 线制造 NACK/卡死 | 驱动自动重试+总线复位后自愈，`err_count` 有记录但恢复后继续正常读数 |
| V8 | 互斥并发 | （可选）另起任务高频调 `bsp_imu_get_stats` + 人工触发读取 | 无优先级反转卡顿；锁等待超时不积累 |
| C0 | 编译链接 | 并入现有 SPL 工程 | 0 error；warning 逐条记录原因 |
| C1 | 回调链路 | 观察 `imu_data_consumer` 输出 | 每 100ms 一条，数值连续无跳变 |

## 4. 数据记录格式约定

- **原始样本行**（可直接粘贴回填）：
  `raw: ax=____ ay=____ az=____ | gx=____ gy=____ gz=____ | t=____`
- **换算样本行**：
  `phy: ax=+0.01g ay=-0.02g az=+1.00g | gx=+0.3 gy=-0.1 gz=+0.2 dps | t=31.25C`
- **统计口径**：每轮 V2/V3/V4 取连续 10 次读数的均值 + 极差；V6 取 `bsp_imu_get_stats` 前后差值。
- **异常上报格式**：`[FAIL Vx R#] 现象 + 错误码 + err_count 增量 + 已排除项`。
