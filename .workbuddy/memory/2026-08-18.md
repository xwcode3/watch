## AHT21 read_data 第 4 个 ACK 总是失败 — 根因诊断（未改代码）

- 现象：`aht21_read_data` 中 `log_i("read 1")` 之后的 `pf_iic_wait_ack` 必失败（前 3 个 ACK 正常）。
- 根因：`log_i("read 1")` 插在 `IICSendByte(0x00)` 与 `IICWaitAck` 之间 = 第 8 与第 9（ACK）时钟之间。
  软 I2C 的 ACK 第 9 时钟由 `IICWaitAck` 产生，elog→`elog_port_output`→`printf` 阻塞串口（115200 下
  log_i≈3ms + `IICWaitAck` 入口 `IIC_DEBUG` printf≈1.4ms），ACK 位窗口被卡 4~5ms，
  AHT21 不再保持 SDA 拉低 → `IICWaitAck`（cErrTime=5、5µs 窗口）读 SDA=1 → NACK。
- 前 3 个字节不失败的原因：它们的 printf 都在函数入口（字节间隙），SCL 低电平停留属合法总线状态。
- 修复方向（已建议、待用户执行）：
  1. 把 `log_i("read 1")` 移到 ACK 判断之后或整段事务外，事务内（Start..Stop 之间）禁止任何 log/printf；
  2. 关掉 `Core/Src/iic.c` 的 `#define IIC_DEBUG`（每个位函数里都有 printf，毒化全总线时序）；
  3. FreeRTOS 下恢复临界区（TEMP-EXP 注释掉的 enter/exit）——`delay_us` 是 TIM2 硬件计数忙等，
     关中断不影响延时；13_AHT21 无临界区能跑是因为它是裸机。
- 涉及文件：`BSP/AHT21/bsp_aht21_driver.c`（L344-352）、`Core/Src/iic.c`（IIC_DEBUG、IICWaitAck）、
  `Middlewares/easylogger/port/elog_port.c`（printf 输出）。

## send_temp_humi_event 单独测试 aht21_read_data — 编译失败诊断 + 改善方案（未改代码）

- 现象：用户想在 `send_temp_humi_event`（FreeRTOS_tasks.c L343）里单独调 `aht21_read_data` 测试，编译报错。
- 三重问题叠加：
  1. **链接错误**：`aht21_read_data` 在 `bsp_aht21_driver.c` L285 是 `static`，头文件未导出 →
     外部调用 = implicit declaration + undefined reference。
  2. **类型错配**：`temp_humi_event_t.temperature/humidity` 是 `float*`（handler.h L31-32），
     用户写 `&event.temperature` = `float**` 传给 `float*` 参数。
  3. **实例未装配**：`aht21_ins`（L333）只设了 `p_iic_driver_instance`，没调 `aht21_instantiate` →
     `pf_read_data=NULL`、`g_inited=0` → 即使编过，`IS_INITED` 直接返回 `AHT21_ERRORRESOURCE`。
- 推荐方案：走 driver 官方入口——
  `aht21_instantiate(&aht21_ins, &iic_driver_interface, &osal_delay_freertos, &osal_time_base_freertos)`
  （内部调 aht21_init 置 g_inited、填 pf_*），再用 `aht21_ins.pf_read_data((void*)&aht21_ins, &temp, &humi)`
  （pf_read_data typedef 第一参为 void*，需强转）。温湿度用局部 `float temp, humi` 接，别用 event 指针字段。
- 备选（快速验证、破坏封装）：去 static + 头文件加声明 + 手动 aht21_init。
- 推进顺序：先按推荐方案改 send_temp_humi_event 解决编译+装配 → 烧录后若返回 AHT21_ERRORTIMEOUT
  → 回到上一轮 3 步修 I2C 时序（移 log_i/关 IIC_DEBUG/恢复临界区）。
- 涉及文件：`Core/Src/FreeRTOS_tasks.c`（L333-367）、`BSP/AHT21/bsp_aht21_driver.c`（L285 static、
  L542 aht21_instantiate）、`BSP/AHT21/bsp_aht21_handler.h`（L31-32 指针字段、L97-106 instantiate 签名）。
