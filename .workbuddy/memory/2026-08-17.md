# 2026-08-17

## iic.c 三函数由直接写寄存器改为标准库 GPIO_Init
- 文件：`Core/Src/iic.c`
- 改动：`IICInit` / `SDA_Input_Mode` / `SDA_Output_Mode` 原用 `port->MODER/OTYPER/OSPEEDR/PUPDR` 直接写寄存器，现改为 StdPeriph `GPIO_InitTypeDef` + `GPIO_Init`。
- HAL→标准库映射：OUTPUT_PP→Mode_OUT+OType_PP；INPUT→Mode_IN；OUTPUT_OD→Mode_OUT+OType_OD；PULLUP→PuPd_UP；NOPULL→PuPd_NOPULL；SPEED_FREQ_HIGH→GPIO_Speed_50MHz（F4 上 OSPEEDR=2 即 50MHz，非 100MHz）。
- 同步删除仅被这三个函数使用的死代码辅助函数 `iic_pin_pos`，避免 unused-function 警告。
- 时钟使能仍由调用方负责（iic_bus_t 无 CLK_ENABLE 成员），IICInit 内保留注释提示。
- 校验：用工程自带 arm-none-eabi-gcc（`/opt/ST/STM32CubeCLT_1.21.0/...`）+ `compile_commands.json` 参数 `-fsyntax-only`，`-Wall` 通过无警告。
