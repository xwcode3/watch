# 2026-07-30 工作日志

## 分散加载 / 飞秒启动方案讨论（仅方案，未改代码）
- 用户问：CMake 管理下如何复现 Keil .sct 的分散加载以实现"飞秒启动"（极速进应用）。
- 结论：CMake+GCC 无 .sct，等价物是 GNU ld 链接脚本（STM32F411XX_FLASH.ld）。
- 关键差异：Keil scatterloader 按区自动生成拷贝代码；GCC 的 Reset_Handler 手写，
  默认只搬 .data/.bss/.tdata/.tbss。新增独立 >RAM AT> FLASH 区必须同步改 startup。
- 零代码改动路径：热函数标 __attribute__((section(".RamFunc")))，
  已被 .data 收走、由现有拷贝循环搬运。
- 飞秒启动杠杆：热路径进 RAM、开 F411 I-Cache、最小化启动拷贝（.bss/.noinit/const 不搬）、
  CCMRAM(0x10000000,64K) 放大缓冲、Bootloader 做减法、FIRST 约束前置。
- 提示：F411 无 QSPI/XIP，W25Q64 只能 SPI 读，不能做执行区。
- 风险重申：App 链接 0x08010000 vs boot_manager.h ApplicationAddress_boot=0x08008000 不一致，
  落地 Bootloader 跳转前必须先对齐，否则 HardFault。
