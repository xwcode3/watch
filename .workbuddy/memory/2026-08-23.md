## OTA + AHT21 并发卡死根因排查
- 现象：ota_task 与 temp_humi(AHT21) 任务单独跑正常，同时跑且串口向 MCU 发数据时偶发卡死。
- 主因：ota.c 命令循环用 `xQueueReceive(Q_YmodemReclength, ..., portMAX_DELAY)` 无限等，唯一唤醒源是 USART1 IDLE 中断(usart.c:337)。`uartx_receive2idle_dma`(usart.c:444) 重武装 DMA(NDTR=4) 与 `xQueueReceive` 之间有窗口；窗口内若数据先到，IDLE 边沿被错过 → 之后再无唤醒 → 永久阻塞。AHT21 任务(prio3)的 printf 轮询忙等(usart.c:179)拉大该窗口，故并发才暴露。
- 叠加问题：① Q 深度1且 item=uint8_t(ota.c:121)，但 ISR 发 uint16_t rec_len(usart.c:359)→长度截断；② USART1_SendByte(usart.c:176) 轮询无锁，多任务 printf 抢同一 TDR；configUSE_NEWLIB_REENTRANT=0，printf 非线程安全；③ 任务栈仅 256 words，configCHECK_FOR_STACK_OVERFLOW=0，易静默溢出。
- 隐患：USART1_Config()(usart.c:231) 把 USART1_IRQn 配成 prio0，ota_usart1_config()(usart.c:320) 配成5；configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY=5，prio0 调 FromISR 非法。需确认工程实际调哪个。
- 建议修复：#1 队列接收加超时+自愈重武装；#2 队列改 uint16_t；#3 缩窗口(Circular DMA 更佳)；#4 printf 发送加 mutex 或开 EasyLogger 异步；#5 开栈溢出检测+栈提到512~1024；#6 统一 USART1 中断优先级为5。
